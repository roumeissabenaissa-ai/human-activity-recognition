# Human Activity Recognition Using Smartphones

## Description

A Machine Learning project focused on automatically recognizing human activities using data collected from smartphone sensors.

The project uses the Human Activity Recognition Using Smartphones (HAR) dataset and includes several steps:

- Exploratory Data Analysis (EDA)
- Data preprocessing and normalization
- Dimensionality reduction using PCA
- Supervised classification
- Unsupervised clustering
- Model evaluation and comparison

## Dataset

Human Activity Recognition Using Smartphones (HAR)

- 10,299 samples
- 561 features
- 6 human activities
- Data collected mainly from accelerometer and gyroscope sensors

### Activities

- WALKING
- WALKING_UPSTAIRS
- WALKING_DOWNSTAIRS
- SITTING
- STANDING
- LAYING

## Machine Learning

### Supervised Models

- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Artificial Neural Network (ANN)

### Unsupervised Models

- K-Means
- Agglomerative Clustering
- DBSCAN

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Objective

The objective is to analyze human movement data and explore different Machine Learning approaches for recognizing and discovering patterns in human activities.
